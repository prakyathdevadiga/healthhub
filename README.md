# HealthHub

HealthHub is a healthcare web application that brings useful healthcare services and information together in one platform.

The main idea behind HealthHub is to make it easier for users to access basic healthcare information without having to use multiple platforms for different purposes.

## Features

### User Authentication
- Create a new account
- Login
- Google Sign-In
- Forgot password
- Logout
- Firebase Authentication

### Dashboard
The dashboard provides access to the main healthcare services available in HealthHub.

It includes:
- Medicine Information
- Nearby Healthcare
- Blood Donor Finder
- Prescription Management
- Medication Reminders
- Emergency Assistance
- Health Profile
- Health Guidance

### Medicine Information

HealthHub uses the openFDA Drug Label API to fetch medicine information.

Users can search for medicines and view details such as:
- Brand name
- Generic name
- Manufacturer
- Product type
- Active ingredients
- Purpose
- Indications and usage
- Dosage
- Warnings
- Side effects
- Pregnancy and breastfeeding information
- Storage information

The API is accessed through a Next.js API route so that the API key is kept on the server side.
